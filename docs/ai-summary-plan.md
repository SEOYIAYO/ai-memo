# AI 메모 요약 기능 계획 문서

## 1. 배경과 목표

- 메모 상세보기 페이지에서 긴 메모를 AI로 요약해 빠르게 파악할 수 있게 한다.
- 모델: 기본 `gemini-3.1-flash-lite` (Google Gemini API). `GEMINI_MODEL` 환경변수로 변경 가능
- 변경 이력: 기본 모델을 `gemini-2.5-flash-lite`로 바꿨다가, 이 프로젝트에서는 신규 사용자 대상 제공 종료(404)로 호출할 수 없어 `gemini-3.1-flash-lite`로 되돌렸다.

## 2. 범위

### 포함

- 상세 페이지(`/memos/[id]`)에 "AI로 요약하기" 버튼 추가
- 버튼을 누를 때만 요약 생성 (자동 요약 아님)
- 요약은 저장하지 않는 일회성 보기 (`Memo` 타입, LocalStorage 스키마 변경 없음)
- 로딩, 에러, 결과 상태 표시
- 요약 결과는 한국어 3문장 이내 문단
- 상세 페이지 신규 생성 (기존 앱에는 상세 페이지가 없었음)

### 제외

- 요약 저장 및 재생성 이력
- 목록 페이지 요약, 자동 요약
- 스트리밍 출력
- 다국어 선택, 요약 형식(불릿 등) 선택

## 3. 제약

| 구분          | 내용                                                                                                                                |
| ------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| 보안          | API KEY는 서버 전용 환경변수 `GEMINI_API_KEY`(`.env.local`)에만 둔다. `NEXT_PUBLIC_` 접두사 금지                                    |
| 모델 설정     | `GEMINI_MODEL`(선택)로 모델을 바꿀 수 있고, 미설정 시 `gemini-3.1-flash-lite`                                                       |
| 호출 구조     | 브라우저는 `/api/summarize`만 호출하고, Gemini 호출은 서버 Route Handler에서만 수행                                                 |
| 입력 검증     | 빈 메모 거부, 10,000자 초과 거부                                                                                                    |
| 형상 관리     | `.env.local`은 git에 올리지 않는다 (`.gitignore`의 `.env*`로 제외됨)                                                                |
| 프로젝트 규칙 | `'use client'` 명시, `any` 금지, 한국어 UI, Tailwind 사용, 외부 상태 관리 라이브러리 금지, 컴포넌트에서 LocalStorage 직접 접근 금지 |

## 4. 설계

### 4.1 화면 흐름

1. 목록(`/`)에서 메모 카드의 제목을 누른다.
2. 상세 페이지(`/memos/[id]`)에서 메모 본문을 마크다운으로 확인한다.
3. "AI로 요약하기" 버튼을 누른다.
4. 요약 중에는 버튼이 비활성화되고 "요약 중..."으로 표시된다.
5. 성공하면 "AI 요약" 박스에 결과가 표시되고, 실패하면 에러 메시지가 표시된다.

### 4.2 API 명세: `POST /api/summarize`

요청

```json
{ "content": "요약할 메모 본문" }
```

응답

| 상태 | 본문                   | 조건                                             |
| ---- | ---------------------- | ------------------------------------------------ |
| 200  | `{ "summary": "..." }` | 성공                                             |
| 400  | `{ "error": "..." }`   | 본문 누락, 빈 문자열, 10,000자 초과, 잘못된 JSON |
| 500  | `{ "error": "..." }`   | API 키 미설정, 서버 내부 오류                    |
| 502  | `{ "error": "..." }`   | Gemini API 실패, 빈 응답                         |

### 4.3 Gemini 호출

- 엔드포인트: `https://generativelanguage.googleapis.com/v1beta/models/{GEMINI_MODEL}:generateContent` (기본값 `gemini-3.1-flash-lite`)
- 인증: `x-goog-api-key` 헤더 (URL 쿼리에 KEY를 넣지 않는다)
- `systemInstruction`으로 "한국어 3문장 이내 요약, 요약문만 출력" 지시
- Gemini 에러 응답 본문은 클라이언트에 그대로 전달하지 않고, 상태 코드만 서버 로그에 남긴다

### 4.4 파일 구성

| 파일                             | 역할                           |
| -------------------------------- | ------------------------------ |
| `src/app/api/summarize/route.ts` | Gemini 호출 Route Handler      |
| `src/app/memos/[id]/page.tsx`    | 메모 상세 페이지 (신규)        |
| `src/components/MemoSummary.tsx` | 요약 버튼과 결과 UI (신규)     |
| `src/components/MemoItem.tsx`    | 제목을 상세 페이지 링크로 변경 |

## 7. 열린 질문과 후속 과제

1. **배포 여부:** 로컬 전용으로 가정했다. 배포하면 요청 제한(rate limit) 등 남용 방지가 필요하다.
2. **요약 형식:** 현재는 3문장 이내 문단이다. 불릿 형식이나 길이 선택이 필요한지 정한다.
3. **요약 저장:** 일회성으로 두었다. 재방문 시 요약을 유지하려면 `Memo`에 필드를 추가하고 LocalStorage 마이그레이션을 고려해야 한다.
4. **Google 프로젝트 접근 거부:** 실제 호출 시 403 `Your project has been denied access`가 발생했다. 키가 속한 프로젝트 문제라 코드로 해결할 수 없고, AI Studio에서 새 프로젝트로 키를 재발급하거나 Google 지원에 문의해야 한다.
